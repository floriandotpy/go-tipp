API-Dokumentation

← Zurück zu Einstellungen

Authentifizierung

Alle Anfragen an die API benötigen den Header:

Authorization: Bearer <dein-token>

Tokens kannst du unter Einstellungen generieren.

Basis-URL

/api/v1

Endpoints

GET /api/v1/matches

Gibt alle Spiele des aktiven Events zurück, sortiert nach Startzeit.

Beispiel-Antwort 
[
  {
    "id": 1,
    "team_a": "Deutschland",
    "team_b": "Frankreich",
    "start": "2026-06-14T18:00:00Z",
    "match_type": "group",
    "event_phase": 1,
    "finished": false,
    "accepts_tipps": true
  }
]

Wenn ein Spiel beendet ist (finished: true), werden zusätzlich die Felder result_a, result_b und ggf. result_aet_a, result_aet_b, result_apen_a, result_apen_b zurückgegeben.

GET /api/v1/tipps

Gibt deine abgegebenen Tipps für das aktive Event zurück.

Beispiel-Antwort 
[
  {
    "match_id": 1,
    "tipp_a": 2,
    "tipp_b": 1,
    "created": "2026-06-10T09:30:00Z",
    "changed": "2026-06-10T09:30:00Z"
  }
]

POST /api/v1/tipps

Tipp für ein Spiel abgeben oder aktualisieren. Wenn bereits ein Tipp für das Spiel existiert, wird er überschrieben.

Request-Body 
{
  "match_id": 1,
  "tipp_a": 2,
  "tipp_b": 1
}
  • match_id — ID des Spiels (Pflicht, > 0)
  • tipp_a — Tipp für Team A (Pflicht, 0–99)
  • tipp_b — Tipp für Team B (Pflicht, 0–99)
Beispiel-Antwort (201 Created / 200 OK) 
{
  "match_id": 1,
  "tipp_a": 2,
  "tipp_b": 1,
  "created": "2026-06-10T09:30:00Z",
  "changed": "2026-06-10T09:30:00Z"
}

201 wenn ein neuer Tipp erstellt wird, 200 wenn ein bestehender aktualisiert wird.

Fehlercodes

Code Bedeutung
400 Ungültiger JSON-Body
401 Fehlender oder ungültiger Token
404 Spiel nicht gefunden / kein aktives Event
409 Spiel gesperrt (bereits gestartet oder Teams unbekannt)
429 Rate-Limit überschritten — bitte kurz warten und erneut versuchen (max. 10 Anfragen/Sek. pro IP)
422 Validierungsfehler (z.B. tipp_a nicht 0–99)
500 Interner Serverfehler

Alle Fehler haben das Format:

{"error": "Fehlerbeschreibung"}

Bei Validierungsfehlern (422) zusätzlich:

{"error": "validation failed", "fields": {"tipp_a": "tipp_a must be between 0 and 99"}}

Beispiele mit curl

curl -H "Authorization: Bearer gtipp_abc123..." \
     https://dein-server/api/v1/matches
curl -H "Authorization: Bearer gtipp_abc123..." \
     https://dein-server/api/v1/tipps
curl -X POST \
     -H "Authorization: Bearer gtipp_abc123..." \
     -H "Content-Type: application/json" \
     -d '{"match_id": 1, "tipp_a": 2, "tipp_b": 1}' \
     https://dein-server/api/v1/tipps
