API-Dokumentation

Alle Anfragen an die API benötigen den Header:

Authorization: Bearer <dein-token>

Basis-URL: /api/v1

GET /api/v1/matches

Gibt alle Spiele des aktiven Events zurück.

Beispiel-Antwort 
[
  {
    "id": 1,
    "team_a": "Deutschland",
    "team_b": "Frankreich",
    "start": "2026-06-14T18:00:00Z",
    "match_type": "group",
    "event_phase": 1,
    "finished": false,
    "accepts_tipps": true
  }
]

GET /api/v1/tipps

Gibt deine abgegebenen Tipps für das aktive Event zurück.

Beispiel-Antwort 
[
  {
    "match_id": 1,
    "tipp_a": 2,
    "tipp_b": 1,
    "created": "2026-06-10T09:30:00Z",
    "changed": "2026-06-10T09:30:00Z"
  }
]

POST /api/v1/tipps

Tipp für ein Spiel abgeben oder aktualisieren.

Request-Body 
{
  "match_id": 1,
  "tipp_a": 2,
  "tipp_b": 1
}
Beispiel-Antwort (200 OK) 
{
  "match_id": 1,
  "tipp_a": 2,
  "tipp_b": 1,
  "created": "2026-06-10T09:30:00Z",
  "changed": "2026-06-10T09:30:00Z"
}

Fehlercodes

Code Bedeutung
400 Ungültiger JSON-Body
401 Fehlender oder ungültiger Token
404 Spiel nicht gefunden / kein aktives Event
409 Spiel gesperrt (bereits gestartet)
422 Validierungsfehler (z.B. tipp_a nicht 0–99)

Beispiel mit curl

curl -H "Authorization: Bearer gtipp_abc123..." \
     https://dein-server/api/v1/matches
curl -X POST \
     -H "Authorization: Bearer gtipp_abc123..." \
     -H "Content-Type: application/json" \
     -d '{"match_id": 1, "tipp_a": 2, "tipp_b": 1}' \
     https://dein-server/api/v1/tipps
